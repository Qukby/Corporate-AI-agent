# Программные требования

Для корректной работы программы, необходимо, чтобы ваше железо соответствовало минимальным требованиям, а также были установлены нужные пакеты и библиотеки.
## Нужные библиотеки

Все нужные библиотеки прописаны в файле requirements.txt, для их установки необходимо прописать следующую команлу: **pip install -r requirements.txt**

Так же необходимо установить модуль ffmpeg, который парсит звук из видеоряда. Команда для его установки: **apt install ffmpeg**.

## Системные требования

Тесты всей системы проводились на сервере со следующим набором компонентов:
- Видеокарта: Nvidia RTX 4090 25GB VRAM
- RAM: 16 GB
- Место на жестком диске: 65 GB

Это самые важные показатели для стабильной работы. Так же система, где проводились тесты - **Linux Ubuntu**.

## Доп требования

Для корректной работы вам нужно скачать из приложения, которым вы пользуетесь видеозапись звонка. Например в **Zoom** есть такая возможность. Далее вам необходимо закинуть скаченный файл в корневую папку проекта и переминовать в **test_meeting.mp4**.

## Что делает каждый модуль

Архитектура сервиса построен на взаимодействии между собой нескольких ИИ микросервисов. Все сервисы реализованы с помощью Python и PyTorch. Вот названия сервисов и что они делают:

## Модуль микросервисов для формирования конспекта

- ### VideoProcessor
Этот сервис реализует отлов кадров из видео для дальнейшего использования другой нейросетью, которая будет составлять конспект. Здесь используется opencv для отлова кадров.
**ВАЖНО!** Ваш видеофайл должен называться test_meeting.mp4. Вы можете изменить это в коде данного модуля.

- ### SpeechTranscriber
Этот сервис переводит речь из подготовленного **wav** файла в текст для дальнейшего использования другой нейросетью, которая будет составлять конспект. Здесь используется модель **Whisper-tiny** от **Open AI**. Она же в свою очередь переводит звук в текст.

- ### SlideAnalyzer
Этот сервис дает описание каждой картинке, чтобы главная нейросеть понимала, когда нужно вставить эту картинку, чтобы конспект выглядел локанично.

- ### ConspectEditor
Этот сервис составляет конспект опираясь на результат работы предыдущих модулей. Благодаря этому она составляет красивый конспект в **MarkDown** формате.

- ### MainOrchestrator 
Мозг нашей архитектуры. Здесь мы собираем все микросервисы, которые я упомянал ранее в одну единую систему. Каждый модуль отрабатывает последовательно и в итоге мы получаем конечный результат в виде красивого конспекта.

## Модуль для составления вопросов по теме и их оценивания

 - ### TestGenerator
 Этот модуль генерирует вопросы используя языковую модель **Qwen2-VL-7B-Instruct**. Благодаря правильно-настроенному промпту модель составляет вопросы, которые практически не отличаются от вопросов, составленных человеком.

- ### AnswerJudge
Это оценщик ответов пользователя. Она построена на архитектуре модели **Qwen2.5-7B-Instruct**. Благодаря ей, модель может качественно оценивать ответы сотрудников и давать развернутые комментарии. Также очень важен промпт для данной модели.

- ### ExamSystem
Мозг нашей системы. Мы объединяем два нейросети в одну. Благодрая этому мы получаем файл с 10 вопросами в *json* формате с названием **generated_questions.json**. Так же после окончания теста, когда пользователь ответил на все вопросы, мы сохраняем полученный результат пользователя так же в файл в формате *json*  с названием **user_test_result.json**. Результаты каждово отдельного ответы так же сохзраняются в этот файл
